RapidCap

Design system · 20 cards

A Windows screen-capture tool built in Rust on GPUI. Dark only, neutral grayscale, one accent and one recording red. Every value in this system was either measured from the reference panel or read out of crates/desktop/src — nothing here is decorative guesswork.

Pure neutral gray — R = G = B on every surface. Colour appears three times and only three times: accent for selection, red for a live capture, amber for failure.

Eight rules

1One spacing value: 9px. Grid gaps, row gaps, group gaps. Compaction shrinks elements, never the gap.
2One radius: 8px, or a pill. 12px on the window itself. Nothing else.
3Raised means pressable, recessed means read-only. Same #1C1C1C fill, opposite shadow. This is the only affordance signal in the product.
4Red means a capture is running. Region frame and recording dot. Errors are amber so failure never reads as recording.
536px minimum target, except the 32px segment slot, which has an arrow-key path.
6Nothing shares an edge. Controls are free-standing. A hairline divider between two buttons makes both harder to read and to hit.
7Motion confirms, never introduces. Four durations. The overlay, the frame, the timer and the tray never animate.
8Every string is under seven words, sentence case, no terminal punctuation, and never shows the user a Rust type.
