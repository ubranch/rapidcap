Rules

  • 24 viewBox always. Render size changes, geometry does not.
  • 1.5px stroke — 1.6 only for minimize and close, which are single lines and read thin otherwise.
  • currentColor everywhere. An icon never carries its own colour except the recording dot and the warning glyph.
  • Never mix filled and outline in one surface. The transport set is the exception and it lives alone in the HUD.
  • No icon-only control without a tooltip, and no tooltip that just repeats the icon's name.
Shipped as a Rust module, not as files. GPUI renders SVG from disk or from an embedded asset, and 28 tiny files in an assets/icons folder would be 28 chances for a path bug. The path data lives as const strings in crates/desktop/src/icons.rs, one Icon variant each, and the element is built in code. Every tile above is in that enum except chevron: it has no caller since the split button came off the mode cards, and it is drawn here only because the unbuilt select control would need it.
