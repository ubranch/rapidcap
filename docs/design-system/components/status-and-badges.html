Floating labels — overlay & HUD

1280 × 720 chrome.exe Click window or drag region · Esc cancel

Background rgba(28,28,28,.92) — the card tone at 92%, so overlay chrome and panel chrome read as one product. Size badge sits 9px inside the selection top-left; the hint pill sits 18px from the display top-right.

All three are one shape. Fixed 30px height, 0 11px padding, line-height:1, display:inline-flex; align-items:center. The first pass gave the size badge 12px/4px padding and the hint 13px/7px, so the two sat on different baselines and different heights whenever they appeared together — visible in the overlay, where the badge and the hint share a screen. Digits use font-variant-numeric:tabular-nums so the badge stops twitching as a drag resizes.

Accessibility contract

  • Status row: role=Status, aria_label mirrors label + pill as one sentence
  • Panel root: role=Application, label "RapidCap screen capture"
  • Mode card: role=Button, aria_keyshortcuts="Enter Space", tab stop
  • Split button: two stops — main pane, then chevron pane with aria_haspopup
  • Segmented: role=radiogroup, one tab stop, arrow keys move between slots
  • Stable ids stay as shipped — rapidcap.capture-region, rapidcap.hud-stop, …
