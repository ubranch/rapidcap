Rules

  • Row height 44px, or 54px when the label carries a second line. Rows are borderless inside a card and use a 6px hover radius.
  • Every control sits right-aligned in its row. The label column is the only thing that ever wraps.
  • Secondary text is 11px #8A8A8A, one line, and explains a consequence — never repeats the label.
  • Focus is the same 2px accent outline everywhere, offset 2px (3px on the toggle, which has no border of its own).
  • No control shows a unit twice. 60 FPS in the value means the label is just "Video frame rate".
None of these exist in code. Settings is written to disk by SettingsStore and read at startup, but nothing in the UI mutates it — every value in the app today comes from Settings::default() or hand-editing the JSON.
