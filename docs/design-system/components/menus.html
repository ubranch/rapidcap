Rules

  • Menu width is fixed per menu — 212px default, 248px where device names live. Items truncate, the menu never grows.
  • Selection is a tick in the icon column, not a highlighted row. Highlight means hover, and one meaning per treatment.
  • Group headers are the same 10px uppercase label used everywhere else in the system.
  • Disabled items stay at 40% opacity. Removing them makes the menu shift between openings.
  • A menu that would be empty shows a sentence instead — never an empty container.
  • Opening a menu marks its trigger: the chevron pane goes #3C3C3C, a chip takes its hover fill.
None of this exists in code. The chevron panes render but open nothing, and the audio chip has no picker behind it. Settings already holds video.fps, video.bitrate, gif.fps and audio, so the menus have somewhere to write — the plumbing is the missing half, not the model.
