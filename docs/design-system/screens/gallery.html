First run. The empty state is recessed — it is a container with nothing in it, not a card you can press — and it spends its space teaching the three hotkeys instead of apologising.
The gallery is a view of the folder, not a database. It lists AppPaths.capture_root sorted by modified time. Delete moves to the Recycle Bin. Nothing is indexed, nothing needs migrating, and a file dropped into that folder by hand shows up like any other — which is the behaviour a capture tool should have.
Filters come from the extension, so they cost nothing: .png/.jpg are Images, .mp4 is Video, .gif is GIF. The screenshot pipeline already switches PNG to JPEG above 2 MB, so both extensions appear under Images.
Thumbnails are the one real cost. Decoding a folder of 4K PNGs on every open will stutter. Generate at 236px wide (2× the tile), cache next to the file in %LOCALAPPDATA%, and render the tile from a placeholder tone until the thumb arrives — never block the window on disk.
