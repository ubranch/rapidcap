Six sections, section labels outside the cards so a card is always one group of related rows. Scrolls as one column; the titlebar keeps a Back arrow because Settings replaces the panel rather than opening beside it.
Every field is a real key. Countdown → countdown_seconds, quality → video.bitrate + preset + tune, dithering → gif.dither, JPEG conversion → screenshot.png_to_jpeg_threshold_bytes and jpeg_quality, hotkeys → HotkeySettings. Nothing was added to make the screen look fuller.
What the screen hides on purpose. schema_version, palette_stats_mode, audio.channels and the raw NVENC preset strings stay out of the UI — they are either derived, or the kind of value that belongs in the JSON for the one person a year who needs it. The footer line names that file so that person can find it.
Hotkey conflicts are the risk. Settings::default() binds Ctrl+Shift+Print Screen for GIF, which Windows Snipping Tool already owns, and global-hotkey registration fails silently today. The field needs a clash state and a real registration result to show it — the amber ring above is the design, not the behaviour.
