Port plan

Sixteen cards, one codebase, six phases. Ordered so that each phase ships something usable on its own and nothing depends on a phase that comes later. Phase 0 is the only one that touches every file.

Phases 1 to 3 are the product. After those, RapidCap looks like the design system, never shows the user a Rust debug string, and tells them when something failed or saved. Phases 4 and 5 are features the app does not have yet — worth building, but nothing in them fixes something broken.
Test debt to expect. window_size.rs asserts the old 360 × 240 bounds, probe.rs and primary_controls_have_stable_ids pin the current control ids, and recording_boundary_is_four_thin_edges pins a 4px frame. All three break in phases 1 and 2 — update them with the change, not after it.
