Card edge treatment

Not a flat stroke. Vertical scan through a row top edge:

#202020  outer border
#414141  inner top highlight — 1px only
#212121
#1A1A1A
#1C1C1C  fill
/* raised — cards, rows, chips */
background: var(--bg-card);
border: 1px solid var(--border-card);
box-shadow: inset 0 1px 0 var(--border-top);

/* recessed — status well, any read-only field */
background: var(--bg-card);
border: none;
box-shadow: inset 0 1px 3px rgba(0,0,0,.55);
Do not apply the highlight to all four sides. It reads as a bevel and the whole panel goes cheap.
Same fill, opposite depth. Raised means pressable; recessed means read-only. That pair is the only affordance signal in the product — there is no third state, and nothing read-only ever gets a border.

Icons

Single-weight line, 1.5px stroke, 24px viewBox. Row icons render at 18px, card icons at 20px, titlebar at 17px. Never mix filled and outline in the same surface — the one exception is the recording dot, which is filled by definition.
