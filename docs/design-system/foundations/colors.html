Amber exists so failure never reads as recording. Red is taken: it means a capture is live. An error bar in #FF2D2D sitting under a red region frame is unreadable, and #C92A2A is the Stop button. --warn is the only colour added beyond the source palette.
Deviation from the source spec: accent is RapidCap's own #3478F6, not Cap's #2382DE — it is already the accent in window.rs and sits in the same hue family. rec and danger are RapidCap additions; the source panel has no recording state to colour.

Contrast

Off · 2.4:1 fails WCAG AA Off · 4.6:1 passes at #A9A9A9
The Off pill carries state meaning, so it is not decorative — #7A7A7A on #3A3A3A measures 2.4:1 and fails AA. Ship the pill text at #A9A9A9 (4.6:1) and keep #7A7A7A for icons at rest only.

Theme decision — dark only

There is no light theme, and that is a decision rather than an omission. Three of the four surfaces are dark by necessity: the HUD and the region overlay float over arbitrary desktop content, and the tray icon has to read on a dark taskbar. A light panel would be the only light surface in the product, and it would need a second full set of raised and recessed shadows — the depth language does not invert, an inner shadow on white reads as dirt.
Code delta: window.rs:107-113 still branches on window.appearance() and carries a full light palette. That branch should go, along with the WindowAppearance match — one palette, no runtime check.
